# Efood Clone

Ένα πλήρες **Full-stack** project που αναπαράγει τις βασικές λειτουργίες της πλατφόρμας efood.

---

## Τεχνολογίες

Το project είναι χωρισμένο σε δύο μέρη:

- **Frontend (Client):** React.js / Vite.
- **Backend (Server):** Node.js, Express.js.
- **Database:** SQLITE3.
- **Server Image Provider:** Cloudinary.

---

## How to run

Ακολούθησε τα παρακάτω βήματα για να τρέξεις το project τοπικά:

### 1. Clone το Repository

### 2. Δημιουργία .env file στο /server που να έχει τα παρακάτω parameters

```
PORT=
SALT_ROUNDS=
JWT_USER_SECRET=
JWT_SHOP_SECRET=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```
